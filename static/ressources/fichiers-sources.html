Mode d'emploi

Ouvrir un fichier source

Trois étapes pour passer de la vidéo au projet.

  1. Décompresser

    Dézippez le dossier téléchargé : vous y trouvez le projet .aep et, selon les tutoriels, ses médias (icônes, images, palette de couleurs).

  2. Ouvrir le projet

    Double-cliquez sur le .aep. Si un média apparaît manquant, faites un clic droit dessus dans le panneau Projet › Remplacer le métrage › Fichier et pointez vers le dossier dézippé.

  3. Décortiquer

    Lancez le tutoriel à côté du projet, sélectionnez un calque et appuyez sur U pour afficher toutes ses images clés.

AstuceAppuyez deux fois sur U pour révéler toutes les propriétés modifiées d'un calque : le moyen le plus rapide de comprendre comment une animation est construite.
